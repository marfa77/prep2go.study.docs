# DELF A2 Listening – Quick Facts

- **Level:** A2 (CEFR)
- **Exam:** DELF A2 (Diplôme d'Études en Langue Française)
- **Authority:** France Éducation International
- **Required for:** French residency and citizenship

## Listening section (Compréhension de l'oral)

| Detail | Value |
|--------|-------|
| Duration | ~25 minutes total |
| Recordings | 3–4 short recordings |
| Content | Everyday conversations, interviews, announcements |
| Playbacks | Each recording played **twice** |
| Format | Comprehension questionnaire (multiple choice, true/false, etc.) |

## Pass requirements

- Listening scored out of **25 points**
- Minimum **5/25** per paper
- Overall DELF A2: 50/100 to pass

## Tips

1. Use the first playback for main ideas, second for details
2. Focus on everyday topics: shopping, transport, appointments, invitations
3. Practice with authentic French audio (European French)
4. Read questions before each recording starts
